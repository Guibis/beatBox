# 🥁 Drum Kit Website

A simple and interactive **Drum Kit** web application that allows users to play drum sounds using their **keyboard** or by **clicking on-screen buttons**. This project is ideal for practicing JavaScript fundamentals such as DOM manipulation, event handling, and audio playback.

---

## 🎯 Features

- 🎹 Play drum sounds using the keyboard keys **Q W E A S D**
- 🖱️ Click on the drum buttons to trigger sounds
- 🔊 Real-time audio playback
- ✨ Visual feedback when a drum is played
- 📱 Responsive layout for desktop and mobile devices

---

## ⌨️ Controls

| Key |
 |---|
 | Q |
 | W |
 | E |
 | A |
 | S |
 | D |

You can press the keys on your keyboard or click the corresponding buttons on the screen.
